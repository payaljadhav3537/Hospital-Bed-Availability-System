# Hospital Bed Availability System

## Introduction
The Hospital Bed Availability System is a Python project developed in a Jupyter Notebook. It helps manage hospital bed records and view bed availability by ward, bed type, and status.

## Features
- View hospital bed records and bed availability counts.
- Add new bed records.
- Search for beds.
- Update bed information and status.
- Suggest available beds based on ward and bed type.
- Find available beds for emergency or ICU needs.
- Display warnings when only a few beds are available.
- Store bed records and status-change history in a database.
- Display bed statuses using different colours.

## Technologies Used
- **Python** – application logic and functions.
- **Jupyter Notebook** – development environment.
- **Tkinter (`tkinter`, `ttk`, `messagebox`)** – graphical user interface.
- **SQLite (`sqlite3`)** – storing and managing bed records in a database.
- **Pandas** – reading and handling table data.
- **NumPy** – counting bed statuses and performing calculations.
- **datetime** – date and time handling.

## Project File
- `Hospital_Bed_Availability_System (1).ipynb`

## How to Run
1. Download the `.ipynb` notebook from this repository.
2. Open it in Jupyter Notebook or Google Colab.
3. Run the notebook cells in order.

**Note:** This project uses Tkinter to create a desktop GUI. It is best run in a local Python/Jupyter environment that supports desktop windows; Google Colab generally cannot display Tkinter windows directly.
